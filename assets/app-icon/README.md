# The app icon

`icon.svg` is the one icon of the app. The title bar draws it, and the build turns it into the icon of `jmeter-ui.exe`
(also used for the window and the taskbar). To change the icon, replace this file; nothing else needs to change.

It was drawn for this project and uses no third-party artwork. It is released under the project licence,
GPL-3.0-or-later, so anyone may use and redistribute it with the program. It does not copy the Apache JMeter logo or
any other mark.
