# Code of conduct

Be respectful. This project is for people who want to build and use a better front end for JMeter, and everyone should be able to take part without being harassed or belittled.

**Expected:** polite and patient answers, criticism aimed at the code and not the person, credit for other people's work, and accepting a "no" on a feature with good grace.

**Not accepted:** insults, personal attacks, discrimination, harassment, sharing other people's private information, and spam.

The maintainer may edit or remove comments, issues and pull requests that break these rules, and may block people who keep breaking them.

To report a problem, use GitHub's "Report content" on the comment, or open a private security advisory on this repository and say it is a conduct matter. Reports are treated privately.
